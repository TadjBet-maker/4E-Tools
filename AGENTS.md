# 4E Tools --- AGENTS

## Источник истины

Перед любой работой прочитай: 1. `AI/PROJECT.md` 2. `AI/UX.md` 3.
`AI/DATABASE.md` 4. `AI/DECISIONS.md` 5. `AI/TASKS.md` 6.
`AI/HANDOFF.md` 7. Затем проверь `git status`, `git diff` и последние
коммиты.

Не полагайся на память предыдущего чата.

## Нельзя

-   Самовольно менять LOCKED UX.
-   Менять архитектурные решения без записи в DECISIONS.
-   Удалять movements или ломать исторические связи.
-   Хранить service-role key в мобильном приложении.
-   Обходить RLS клиентским кодом.
-   Делать TAKE/RETURN простыми клиентскими UPDATE.
-   Считать серверную операцию успешной до подтверждения.
-   Переписывать рабочую часть приложения без необходимости.

## Definition of Done

Задача считается завершённой, только если: - требования задачи
выполнены; - `npm run typecheck` проходит; - `npm run lint` проходит; -
`npm test` проходит для существующих тестов; - затронутая навигация
запускается без ошибки; - для новой критической бизнес-логики
добавлены/обновлены тесты; - loading/error/empty состояния обработаны,
если применимо; - TASKS и HANDOFF обновлены; - важное новое решение
записано в DECISIONS; - секреты не попали в Git; - сделан небольшой
логичный commit.

До появления конкретного production build-script не выдумывать
`npm run build`. Android-сборка выполняется через утверждённую
Expo/EAS-команду после её добавления в проект.

## Handoff

Перед передачей другой AI-модели HANDOFF обязан содержать: сделанное,
текущую задачу, изменённые файлы, миграции, известные ошибки, проверки,
следующий шаг и что нельзя менять.
