# 4E Tools AI Starter v2.4

Это согласованный пакет спецификации перед первой строкой
application-кода.

1.  Открой `AGENTS.md`.
2.  Затем AI читает документы из `AI/` в указанном порядке.
3.  Папка `AI` намеренно не скрытая, чтобы её было видно на телефоне.
4.  Следующий шаг после аудита --- инициализация Expo/TypeScript
    foundation.

Важно: визуальные файлы утверждённого брендинга/макетов должны быть
добавлены отдельно в `assets/branding/` перед pixel-perfect реализацией.
